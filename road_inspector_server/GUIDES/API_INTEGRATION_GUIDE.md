# API Integration Guide: Road Inspector Hybrid Pipeline

This guide is designed for external applications and websites that need to programmatically access the Road Inspector FastAPI service. 

The API uses a **hybrid architecture**: it first runs parallel YOLOv8 and YOLOv12 models to locate pavement defects, fuses their detections to prevent duplicates, and then passes the mathematically bounded image to a 7B parameter Vision-Language Model (Qwen2.5-VL-7B-Instruct) to generate an engineering-grade textual report and assign severity scores based strictly on road user danger.

---

- **Authentication**: All requests must include an `X-API-Key` header.
- **Payload Format**: JSON

*Connection Details:*
- Host: `sparc-nicole-given-thousand.trycloudflare.com`
- Protocol: `HTTPS` (Port 443)
- API Key: `road-inspector-secret-key-2024`

## 2. Constructing the Request

The API expects a JSON body containing a base64 encoded image and optional GPS coordinates.

### Request Schema

| Field | Type | Required | Description |
|---|---|---|---|
| `image_b64` | string | Yes | The raw image file, strictly base64 encoded as a string. Do NOT include HTML data URI prefixes like `data:image/jpeg;base64,`. |
| `location` | object | Yes | An object containing `lat` and `lon` floats. Used contextually by the VLM. |

### Example cURL Request

```bash
# First, convert your image to base64
BASE64_IMG=$(base64 -w 0 path/to/pothole.jpg)

# Send the request
curl -X POST "http://SERVER_IP:17612/analyze" \
     -H "Content-Type: application/json" \
     -H "X-API-Key: road-inspector-secret-key-2024" \
     -d '{
           "image_b64": "'"$BASE64_IMG"'",
           "location": {
             "lat": 34.0522,
             "lon": -118.2437
           }
         }'
```

## 3. Parsing the Response

For maximum performance and lowest latency, the API returns **only JSON metadata**. It does *not* return heavy base64 image strings. Your client application is responsible for utilizing the coordinate metadata to draw bounding boxes on your local copy of the image if visual rendering is desired.

### Response Schema

The response is a JSON object with a single `report` key containing the following structure:

```json
{
  "report": {
    "summary": "3 defect(s) detected. 1 high-severity issue(s) requiring immediate attention.",
    "boxes": [
      {
        "id": "D0",
        "class": "pothole",
        "label": "Pothole",
        "bbox_xyxy": [1529, 486, 1726, 1065],
        "severity": "high"
      },
      {
        "id": "D1",
        "class": "crack",
        "label": "Longitudinal Crack",
        "bbox_xyxy": [1065, 469, 1209, 537],
        "severity": "moderate"
      }
    ],
    "report_markdown": "# Pavement Distress Repair Report\n\n## Overview\n..."
  }
}
```

### Understanding the Fields

1. **`summary`**: A brief string auto-generated by the pipeline calculating the total defects and high-priority flags.
2. **`boxes`**: An array of isolated defects detected by the dual YOLO integration. 
   - `id`: The unique tracking ID (e.g., `D0`). The VLM explicitly references this ID in the `report_markdown`.
   - `bbox_xyxy`: Absolute pixel coordinates `[x_min, y_min, x_max, y_max]` representing the top-left and bottom-right corners of the bounding box relative to the original image resolution.
   - `severity`: Graded by the VLM. Will always be `low`, `moderate`, or `high`.
     - *Low*: Minor aesthetic issues.
     - *Moderate/High*: Scaled linearly based on the level of physical danger the defect poses to road users or vehicles.
3. **`report_markdown`**: A highly detailed, multi-paragraph markdown string generated by the VLM serving as a full engineering report aimed at road maintenance crews.

## 4. Client-Side Rendering Example (Python/OpenCV)

Because the API strips the image payload to reduce bandwidth, here is a standard example of how an external Python backend might ingest the API's JSON response and apply the bounding boxes to the original file for a frontend user:

```python
import cv2
import requests
import base64

def analyze_and_draw(image_path: str):
    # 1. Read and encode the local image
    with open(image_path, "rb") as f:
        img_b64 = base64.b64encode(f.read()).decode()
        
    # 2. Call the API
    resp = requests.post(
        "http://SERVER_IP:17612/analyze",
        headers={"X-API-Key": "road-inspector-secret-key-2024"},
        json={"image_b64": img_b64, "location": {"lat": 0.0, "lon": 0.0}}
    )
    data = resp.json()["report"]
    
    # 3. Read image with OpenCV
    img = cv2.imread(image_path)
    
    # 4. Draw the boxes and severities locally
    for box in data.get("boxes", []):
        x1, y1, x2, y2 = box["bbox_xyxy"]
        severity = box["severity"]
        b_id = box["id"]
        
        # Color code: Red=High, Orange=Moderate, Green=Low
        color = (0, 0, 255) 
        if severity == "moderate": color = (0, 165, 255)
        elif severity == "low": color = (0, 255, 0)
        
        cv2.rectangle(img, (x1, y1), (x2, y2), color, 6)
        cv2.putText(img, f"{b_id}: {severity}", (x1, y1 - 10), 
                    cv2.FONT_HERSHEY_DUPLEX, 1.2, color, 3)
                    
    # 5. Output the finished product
    cv2.imwrite("frontend_display_ready.jpg", img)
    print(data["report_markdown"])
```

## Troubleshooting

- **500 Internal Server Error**: Often caused by the VLM memory pool being exhausted during extreme concurrent load. The server queue maxes out at `max_num_seqs=4` to protect the 24GB VRAM.
- **400 Bad Request**: Ensure the Base64 string is perfectly raw. Do not include URL-safe padding or HTML prefixes.
- **Empty `boxes` array**: The dual YOLO Non-Maximum Suppression (NMS) threshold determined no defects lived beyond the 0.15 confidence threshold. The image is considered clean.
